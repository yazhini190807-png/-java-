# Java Simple Programs

A collection of simple Java programs for practicing beginner-level concepts.

## Programs

- `StudentManagementSystem.java` — add, view, search, update, and delete student records.
- `CountOccurrenceOfEachCharacter.java` — count each character in entered text.
- `HandlingException.java` — demonstrate exception handling using `try`, `catch`, and `finally`.
- `MultithreadedApplication.java` — demonstrate two threads running.
- `PalindromeOrNot.java` — check whether a word is a palindrome.
- `WordCountInText.java` — count words in entered text.

## Requirements

- Java JDK 8 or later

## Compile and run

Open Command Prompt or a terminal in this folder. Compile and run one program at a time. For example:

```bash
javac WordCountInText.java
java WordCountInText
```

Use the matching `.java` filename and class name for each other program.

## Note

The Student Management System keeps records in memory only. Student data is not saved after the program exits.
